# Hunger Trial

## Descripción
Hunger Trial es un vertical slice donde debes derrotar un jefe que dispara constantemente hacia ti, Esquiva sus ataques y ataca cuando sea posible. ¿Quién caerá primero?

## Objetivo
Derrotar al jefe antes de que te derrote a ti.

## Controles
- **W** – Arriba.
- **S** – Abajo.
- **A** – Izquierda.
- **D** – Derecha.
- **SPACE** – Disparar.

## Play Loop
1. Explora el mapa y busca al jefe.
2. El jefe aparece al acercarte.
3. Esquiva sus ataques y dispara.
4. Si ganas: pantalla de recompensas.
5. Si pierdes: pantalla de reintentar.

## Características
- Combate tipo bullet-hell estilo Undertale
- Patrón de ataque del boss escalable por capítulos
- Sistema de progresión permanente (estadísticas)
- 3 capítulos con dificultad creciente

## Plataforma
- Windows PC / WebGL

## Tecnología
- Unity
- C#
- 2D
